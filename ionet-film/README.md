# THE WORLD'S IDLE MACHINES

A 60-second cinematic film about **io.net**, built entirely in code with [Remotion](https://www.remotion.dev/), React and TypeScript.

* 1920×1080 · 30 fps · 1,800 frames · H.264 MP4
* All visuals are code-generated (SVG, Canvas and CSS). No stock footage, images or downloaded assets.
* The score and sound design are synthesised by a script (oscillators and noise). No audio samples.
* Subtitles are burned in, and also exported as `.srt` and `.vtt`.
* Voiceover support is built in, ready for your own recordings (see [NARRATION.md](NARRATION.md)).

## The story

| Time | Act | What you see |
|---|---|---|
| 0–10 s | **The Problem** | Rainy Lagos at night: skyline, cable-stayed bridge, lagoon reflections, lightning. An engineer's AI project stalls: *TRAINING PAUSED — insufficient compute*. |
| 10–22 s | **The Invisible Resources** | Idle GPUs: an office in Toronto, a university lab in Bengaluru, a data hall in Seoul, then a montage grid of idle machines worldwide. |
| 22–38 s | **The Discovery** | A dark dotted globe. GPU nodes ignite outward from Lagos and connect through golden arcs. io.net is introduced, and the network converges in an anamorphic flare. |
| 38–50 s | **The Possibility** | Dawn. Her (fictional) workload resumes on distributed workers, training completes, and a flood-risk map of Lagos sweeps onto the screen. |
| 50–60 s | **The Reveal** | Pull back to the glowing global network, then the io.net end card: *Distributed GPU compute. Connected for what's next.* |

## Quick start (step by step for beginners)

### 1. Install Node.js
Download the **LTS** version from <https://nodejs.org> and install it. Check it worked by opening a terminal and running:

```bash
node -v   # should print v18 or newer
```

### 2. Install the project
```bash
cd ionet-film
npm install
```

### 3. Preview it live (optional)
```bash
npm run studio
```
This opens Remotion Studio in your browser, where you can scrub the timeline frame by frame. Edits to the code update the preview instantly.

### 4. Render the MP4
```bash
npm run render
```
The video is written to **`out/the-worlds-idle-machines.mp4`**.

The first render downloads a headless Chrome automatically, which takes about a minute. The render itself takes roughly 10–20 minutes on a typical 4-core laptop.

> **No internet, or the Chrome download is blocked?** Point Remotion at a Chrome or Chromium you already have:
> ```bash
> REMOTION_BROWSER_EXECUTABLE="/path/to/chrome" npm run render
> ```

## Customising

Almost everything you'd want to change lives in **`src/config.ts`**:

| Setting | What it does |
|---|---|
| `VOICEOVER.mode` | `'none'` (default), `'lines'` (ten files `public/voiceover/vo-01.wav` … `vo-10.wav`) or `'full'` (one file `public/voiceover/full.wav`) |
| `SCORE.volume` / `duckedVolume` | Music level. The music is lowered automatically under the voiceover. |
| `SUBTITLES.burnIn` | `false` for a clean picture (the `.srt` is still generated) |
| `LOGO.file` | Path to an official logo file in `public/`. While it's `null`, a typographic **placeholder** wordmark is shown. |

### Using the official io.net logo
This project doesn't bundle the official logo, and no external assets were downloaded. To use it:
1. Get an approved logo file (SVG or PNG) from io.net's brand resources, and confirm you're allowed to use it.
2. Save it as `public/ionet-logo.svg`.
3. In `src/config.ts`, set `LOGO.file` to `'ionet-logo.svg'`.

### Changing narration text or timing
Edit **`src/data/narration.json`**. It is the single source of truth for:
* the burned-in subtitles,
* `subtitles/the-worlds-idle-machines.srt` and `.vtt` (regenerated by `npm run subtitles`),
* where each voiceover file starts (`lines` mode),
* the act boundaries used by the film and the soundtrack.

### Changing the music
Edit `scripts/generate-soundtrack.mjs`, then run `npm run audio`. Its sections are commented: rain, thunder, drone, heartbeat, idle hum, piano, whooshes, impacts, pads, ignition chimes, hope arpeggio and logo shimmer.

## Project layout

```
ionet-film/
├── src/
│   ├── config.ts              ← film settings (voiceover, logo, subtitles, music)
│   ├── data/narration.json    ← narration lines + timings (drives subtitles & VO)
│   ├── data/geo.ts            ← hand-drawn simplified continents + city nodes
│   ├── Film.tsx               ← assembles acts, overlays, audio
│   ├── scenes/                ← Act1Problem … Act5Reveal
│   └── components/            ← Globe, Lagos skyline, Engineer, Rain, GPU hardware,
│                                 screens/flood map, flares, grain, letterbox, subtitles
├── scripts/
│   ├── generate-soundtrack.mjs  → public/audio/score.wav
│   └── generate-subtitles.mjs   → subtitles/*.srt, *.vtt
├── subtitles/                 ← generated subtitle files
├── public/voiceover/          ← put your recordings here
├── NARRATION.md               ← narration script with timings and recording tips
└── out/                       ← rendered video (git-ignored)
```

## Troubleshooting

* **`getaddrinfo ENOTFOUND` while downloading Chrome**: your network blocks the download. Use `REMOTION_BROWSER_EXECUTABLE` (see above).
* **Render is slow or runs out of memory**: lower the parallelism with `npm run render -- --concurrency=2`.
* **No sound**: make sure `public/audio/score.wav` exists (`npm run audio`). `npm run render` creates it automatically.
* **Voiceover file not found**: check the file names match `vo-01.wav` … `vo-10.wav` and that `VOICEOVER.extension` matches your file type.

## Disclaimers

* The engineer, her FLOODWATCH-LAGOS project and all on-screen figures are **fictional**. The film doesn't claim that io.net powered any real flood prediction, and it says so in the final seconds.
* The globe's nodes and arcs are an artistic visualization, not real network data.
* The "io.net" wordmark is a placeholder in a generic typeface. Replace it with the official logo where permitted.
